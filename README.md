
# CSCI 4200 Computer Architecture

## Lab 0

The purpose of this lab is to introduce very basic bit-level operations in C. You will compile and run the provided C
program, and then use it to answer the questions in Canvas. This is a graded assignment.

---

### Step 1

Compile the provided `intro.c` file:

`gcc -Wall -o intro intro.c`

### Step 2

Run the resulting executable:

`./intro`

### Step 3

Using the output of the program and visually inspecting the contents of the C program itself, answer the questions
on Canvas.
